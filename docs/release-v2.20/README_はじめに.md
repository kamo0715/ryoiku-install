# v2.20 高学年〜高校生向け 利用者用帳票更新

療育カリキュラム管理 v2.20 | 小学校高学年〜高校生向け 利用者用スケジュール改修
==============================================================

【変更内容】
・v2.19で追加した「利用者用・1日の流れ」の帳票表現とデザインを年齢相応に調整しました。
・見出し：「1日の活動スケジュール」。「きょうの よてい」等の幼い標準表現を廃止しました。
・「できた」チェック欄を「完了」に変更しました。
・色や装飾を抑えた時間割形式に変更。活動時刻／活動内容／順序／完了チェック欄を明確に表示します。
・PDF / Word / Excelを同じ表記で出力します。A4横1枚、最大12項目。
・休憩の表示は可能ですが、活動を勝手に省略・統合しません。「活動ごと」モードの統合だけは利用者の選択に従います。
・Minecraft、非Minecraft、複数カリキュラムの組み合わせに対応します。
・最後に表示するコメントの初期値を「予定の変更や休憩が必要なときは、スタッフに相談してください。」へ変更しました。
・アプリの入力画面での説明文と入力例も、高学年〜高校生に適した表現へ修正しました。
・児童本人の氏名は引き続き初期状態で非表示。明示チェックがあるときだけ表示されます。
・職員用・関係機関用帳票、AI送信前匿名化処理、データ構造、保存済み計画を変更しません。

【v2.19からv2.20への更新手順】
1. 事業所で利用を止め、現在のv2.19が稼働していることを確認してください。
2. サイト一式、データベース、.env・秘密鍵・APIキーを安全な場所へバックアップしてください。
3. 「ryoiku_v2_20_student_schedule_ftp_patch.zip」を展開します。
4. 既存の設置先と同じフォルダ構成で、次の3ファイルのみFTPSで上書きします。
    _private/app/VERSION
    _private/app/child_day_flow.py
    _private/app/templates/day_flow.html
5. 設置済みのアプリを再読み込みし、バージョンが2.20になっていることを確認してください。
6. 架空データで「活動計画詳細 → 1日の支援の流れ → 利用者用PDF」を出力します。
7. PDF / Word / Excelの3形式と、職員用・関係機関用の出力を確認してください。

【重要】
・この差分ZIPの適用元は **v2.19** です。v2.18以前へ直接適用しないでください。
・利用者の実データ、DB、.env、秘密鍵、APIキー、vendor、index.cgi、.htaccessには変更を加えません。
・既存環境への全機能ZIP丸ごと上書きは避けてください。全機能ZIPは新規導入用です。
・表示名は個人の理解度と本人の希望に応じて編集できます。易しい表現が必要な場合も、年齢に対して敬意ある文を推奨します。
・氏名・学校名の不要な転記、時刻の誤り、活動が長時間に偏っていないかを職員が確認してから配布してください。
・A4横に入りきらない場合は、活動名を修正・「活動ごと」表示を選択してください。予定は自動削除しません。
・「今回の帳票」向けの入力は保存済み個別支援計画を書き換えません。
・ローカルでPDF / DOCX / XLSX出力とページ数、職員用の基本出力を検証済みです。
・ロリポップ本番環境への適用・外部AI連携の実送信検証は行っていません。

【利用者用出力操作】
活動計画詳細 → 1日の支援の流れ → 実施日・開始時刻 → 活動の選択・順番・休憩を設定
 → 「5. 利用者（小学高学年〜高校生）用の表示設定」
 → 表示単位・帳票タイトル・連絡メモ・氏名表示を選ぶ
 → 職員の内容確認チェックを入れる → 利用者用 PDF / Word / Excelを出力

# セキュリティ・個人情報保護

このコードは児童・生徒の支援計画、事業所職員のアカウントやAI連携を扱うため、テストでは必ず架空データを使用してください。

- AI連携時はプレビューを確認し、氏名・学校名・住所・連絡先・自由記述の再識別可能情報が残存しないか点検します。
- 「匿名化済み」との表示があっても特定可能性が完全にゼロになるとは保証できません。複数の情報の組み合わせにも注意。
- 外部AIサービスへのデータ送信の可否、必要な同意、契約、情報管理ルールを事業所で確認してください。
- 実利用者のログ・個別支援計画・PDFはGitHubへ保存しません。秘密情報はサーバー側で厳重に保管します。
- 新規リリースごとに認証、閲覧権限、エラーログ・API送信プレビュー、バックアップと復旧を検証してください。

療育カリキュラム管理 v2.19 — 利用者（児童・生徒）向け「きょうのよてい」出力機能
========================================

【新機能】
・既存の「1日の支援の流れ」画面に「利用者（児童・生徒）用」を追加しました。
・PDF／Word（DOCX）／Excel（XLSX）の3形式に対応。A4横1枚、最大12項目。
・活動の時間順・活動名・「できた」チェック欄を大きく表示します。
・Minecraft／それ以外／両方の組み合わせ、複数カリキュラム、休憩、準備、片付けに対応。
・表示形式：「活動ごと」（同一計画の連続手順を1つにまとめる）／「手順ごと」（最大12項目）。
・職員が利用者向け活動名や見出しを簡単な言葉に編集できます。
・利用者名は初期設定では出力せず、必要時にチェックを付けて表示します。
・評価、職員の支援方法、申し送り、目標、配慮事項、内部メモは利用者用へ自動転記しません。
・出力前に職員による内容確認チェックを必須とします。
・空欄・長文・12項目超過はエラー表示。予定や文は黙って省略しません。
・入力内容は一時的な出力に用い、元の活動計画は書き換えません。

【既存v2.18からの更新（差分ZIPの使用方法）】
1. 現在のバージョンが v2.18 であることを確認してください。
2. 必ず利用者の操作を停止し、サイトファイル・DB・設定・秘密鍵等をバックアップしてください。
3. 「ryoiku_v2_19_child_flow_ftp_patch.zip」を展開します。
4. 展開された _private/app/ 以下の7ファイルを、サーバー上の同じ場所へFTPSでアップロードします。
   既存ファイルは上書き、新規 child_day_flow.py を追加してください。
5. _private/app/VERSION が 2.19 であることを確認して再読み込みしてください。
6. 架空の利用者情報で「活動計画詳細」→「1日の支援の流れ」→「利用者用PDF」を確認します。
7. 職員用・関係機関用の出力が従来通り動くことも確認してください。

【重要】
・差分更新は _private/app/data、DB、.env、秘密鍵、APIキー、vendor、index.cgi、.htaccess を上書きしません。
・全機能ZIPは新規設置用です。稼働中サイトへ丸ごと上書きする用途には使用しないでください。
・公開パス、FTPS接続情報や事業所独自の環境設定は既存v2.18の手順を維持してください。
・利用者が自分で理解できる活動名を設定し、配布前に内容・日時・氏名・学校名等を確認してください。
・実運用では本人の希望、個別支援計画、職員の安全確認を優先してください。
・AI連携の匿名化ロジックに今回変更はありません。
・ローカルで生成テストを実施済み。ロリポップ実機上の公開・操作テストは行っていません。

【操作】
活動計画の詳細 → 「1日の支援の流れ」
 → 実施日・開始時刻 → 最大8件の活動選択・順番、準備・休憩・片付け
 → 各活動の「利用者用の活動名」を必要に応じて編集
 → 「5. 利用者（児童・生徒）用の表示設定」で単位・見出し・ひとこと・氏名表示を設定
 → 内容を確認し確認チェック → 「利用者用 PDF / Word / Excel」
※ 活動ごと形式ではカリキュラム内の連続した手順を1項目にまとめます（所要時間を合算）。
※ 手順ごと形式では各手順を個別表示し、12項目を超える場合は出力できません。

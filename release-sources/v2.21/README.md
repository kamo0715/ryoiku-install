# v2.21 (2026-11-19)

カリキュラム作成画面から、そのまま1日の支援の流れを編集し、PDF/Word/Excelで出力できます。

- 新規カリキュラム生成後に日別編集画面へ直接進むか、計画詳細を開くか選べます。
- 作成済みカリキュラムからも日別編集画面を直接開けます。
- 個人情報を最小化する外部AI送信前確認を維持します。
- v2.20のPDF/文章転記後の保存先修正を含みます。

`_private/app/` に、v2.20からv2.21への固定ソース差分を保持します。
`tools/assemble-v2.20.py` でv2.20完全版を復元した後、
`python3 scripts/build_v221_release.py --out dist/v2.21` でv2.21完全版と差分ZIPをビルドします。

Docker LANテスト版は `docker-lan-v2.21/` を参照してください。

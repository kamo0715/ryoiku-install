# v2.23（2026-11-19）新規カリキュラム複数同時生成

1回の操作で **新しく生成する** カリキュラムを2～8件選択し、ジャンル・活動時間・テーマ・配慮事項を個別に指定します。複数の保存済みカリキュラムを選ぶ従来の機能とは別です。

- 選んだ全活動を個別の計画として生成し、ひとつの「1日の流れ」編集画面へ自動で追加
- 外部AIには各活動ごとに限定した送信内容だけを個別に渡し、複数件まとめて職員が確認
- AIの個々の失敗・時間不一致・分類不一致時は生成結果を保存しない
- DB登録はSQLiteトランザクションで全件確定または全件ロールバック
- 既存の職員用／関係機関用／利用者用PDF・Word・Excel出力、複数活動と休憩・順番の編集を維持
- 実在する児童・生徒の個人情報をHTTPテスト版に入力しないこと

配布ファイルは `python3 scripts/build_v223_release.py --out dist/v2.23` で、固定されたv2.20ソースとv2.21/2.22/2.23差分から再構築できます。
